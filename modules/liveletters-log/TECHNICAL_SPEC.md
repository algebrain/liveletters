# liveletters-log

## Назначение

Слой структурированного журналирования для всех крейтов LiveLetters. Пишет логи в JSON-формате с временными метками.

## Зона ответственности

- запись информационных, предупредительных и ошибочных сообщений;
- настройка через `liveletters-config` (ротация по размеру и числу файлов, уровень, назначение);
- инициализация логгера один раз при старте `lltt`.

## Зависимости

- `liveletters-config` — чтение настроек журналирования из глобального конфига;
- `liveletters-i18n` — (через workspace, косвенно).

## Структура

- `src/lib.rs` — `log_info`, `log_warn`, `log_error`;
- инициализация логгера через глобальный конфиг.

## Формат записей

Каждая запись — одна строка JSON:
```json
{"timestamp":"2026-06-08T12:00:00.000Z","level":"info","message":"sync.pull received=1"}
```
