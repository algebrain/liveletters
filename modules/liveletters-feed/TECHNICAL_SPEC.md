# `liveletters-feed` — TECHNICAL_SPEC

## Назначение

Крейт реализует настоящую ленту подписок для `lltt feed`. Он не показывает собственные посты текущего пользователя только потому, что они есть в локальной БД.

## Фильтрация

Лента строится по текущей идентичности:

```rust
let subscribed = identity.subscriptions();
let owned = identity.resources_owned();
```

Пост попадает в ленту, если:

- `post.resource_id` есть в подписках;
- `post.resource_id` не входит в собственные ресурсы пользователя.

`--limit` применяется после фильтрации и сортировки.

## Сортировка

`Store::list_posts()` возвращает посты новые сверху:

```sql
ORDER BY created_at DESC, post_id DESC
```

`feed` сохраняет этот порядок.

## Тесты

- `apps/lltt/tests/cli_feed.rs`:
  - пустая лента;
  - собственный пост не показывается;
  - подписанный ресурс показывается;
  - неподписанный ресурс не показывается;
  - `--limit` режет новые сверху;
  - отсутствие текущего пользователя даёт ошибку контекста.
