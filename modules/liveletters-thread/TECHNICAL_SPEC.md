# liveletters-thread

## Назначение

`liveletters-thread` — командный крейт `lltt thread`. Печатает обсуждение (запись + комментарии в виде дерева) для заданной `post_id`.

## Зона ответственности

- Разбор `Args` (один позиционный аргумент `post_id`).
- Запрос `get_post_thread` через `AppCore`.
- Построение дерева комментариев по `parent_comment_id`.
- Печать шапки поста и отсортированного по `created_at` дерева.
- Ничего не записывать в БД, не отправлять почту.

## Что модуль не должен делать

- знать про clap-дерево всего бинаря `lltt`;
- зависеть от других командных крейтов;
- удалять или скрывать комментарии;
- загружать комментарии лениво (всё дерево собирается за один запрос к `Store`);
- использовать `unix_to_ymdhms` из `liveletters-feed` (для уменьшения связности; временны́е метки не печатаются).

## Граничные случаи

| Случай                                          | Поведение                                                                                |
|-------------------------------------------------|------------------------------------------------------------------------------------------|
| `post_id` не существует                          | `ThreadError::AppCore(AppCoreError::PostNotFound { post_id })`                            |
| У поста нет комментариев                        | Печатает `комментарии: 0` и `(нет комментариев)`                                          |
| Глубокая вложенность (>3 уровней)               | Печатается как есть, отступы фиксированной ширины (4 пробела на уровень)                  |
| Цикл в `parent_comment_id` (битые данные)        | Узлы-сироты печатаются как корни                                                         |
| Комментарий с `parent_comment_id` из другого поста | Узел-сирота; печатается как корень                                                       |
| Очень длинное тело комментария                  | Печатается с отступом 8 пробелов; ограничения на длину нет                               |

## Решения, которые могут поменяться

- В текущей версии дерево строится по `parent_comment_id`. Если в БД появятся `path`/`depth` колонки, можно переключиться на них для производительности.
- Формат дерева (префиксы `•` и `↳`) выбран для читаемости; в будущем возможен JSON-вывод (`--json`).
- Сейчас сортировка — по `created_at` в пределах одного уровня вложенности. Внутри уровня возможно неупорядоченное отображение, если в БД время указано с точностью до секунды.

## Текущее состояние

- `Args { post_id: String }` (позиционный аргумент).
- `run` → `get_post_thread` → `print_thread`.
- `print_thread` использует `print_kv` (счётчик) + рендеринг дерева.
- 2 unit + 3 integration + 2 e2e тестов.

## Критерии готовности

- `cargo build -p liveletters-thread` зелёный.
- `cargo test -p liveletters-thread` зелёный (2 unit + 3 integration).
- `cargo test -p lltt --test cli_thread` зелёный (2 теста).
- `cargo clippy -p liveletters-thread --no-deps -- -D warnings` без замечаний.
