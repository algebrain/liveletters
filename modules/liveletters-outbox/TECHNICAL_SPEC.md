# liveletters-outbox

## Назначение

`liveletters-outbox` — командный крейт `lltt outbox`. Печатает список неотправленных событий, лежащих в локальном `Store`. Команда read-only и не инициирует сетевых вызовов.

## Зона ответственности

- Разбор `Args` (clap-деривация).
- Запрос `get_pending_outbox` через `AppCore`.
- Печать таблицы.
- Ничего не записывать в БД, не отправлять почту, не трогать `subscriptions`.

## Что модуль не должен делать

- знать про clap-дерево всего бинаря `lltt`;
- зависеть от других командных крейтов;
- фильтровать события (`--filter` — отдельная задача);
- удалять события из `outbox` (это делает `liveletters-lltt-sync` после успешной отправки);
- выводить `message_body`.

## Граничные случаи

| Случай                                          | Поведение                                                                                |
|-------------------------------------------------|------------------------------------------------------------------------------------------|
| БД не инициализирована                          | `OutboxError::Store(StoreError::...)`                                                     |
| `outbox` пуст                                    | Печатает `неотправленные события: 0` и `(пусто)`                                          |
| Много событий (>100)                            | Таблица с автоматическим выравниванием колонок; ограничения на размер нет                |
| События с одинаковыми `event_id`                 | Возможно при ручном редактировании БД; печатаются как есть, без дедупликации              |

## Решения, которые могут поменяться

- Добавить `--limit` для ограничения вывода.
- Добавить `--event-type <type>` для фильтрации.
- В перспективе — флаг `--raw` для вывода `message_body` (для отладки).

## Текущее состояние

- `Args { action: OutboxAction::List }`.
- `run` → `get_pending_outbox` → `print_summary`.
- `print_summary` использует `print_kv` (заголовок) + `print_table` (тело).
- 3 integration + 2 e2e тестов.

## Критерии готовности

- `cargo build -p liveletters-outbox` зелёный.
- `cargo test -p liveletters-outbox` зелёный (3 integration).
- `cargo test -p lltt --test cli_outbox` зелёный (2 теста).
- `cargo clippy -p liveletters-outbox --no-deps -- -D warnings` без замечаний.
