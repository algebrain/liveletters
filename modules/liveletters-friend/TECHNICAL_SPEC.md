# `liveletters-friend` — TECHNICAL_SPEC

## Цель

Команда `lltt friend <адрес>` даёт указанному пользователю право видеть
записи текущего пользователя с видимостью `friends_only`.

Это не подписка на текущего пользователя и не рассылка старых записей.
Получатель увидит приватные записи только если отдельно подпишется на
ресурс владельца или получит доступ к ним другим будущим способом просмотра.

## Архитектура

```
apps/lltt
   └─ Command::Friend(liveletters_friend::Args)
          └─ liveletters_friend::run
               ├─ Store::open_for_home_dir(ctx.state_home)
               ├─ Store::get_user_settings_record(ctx.identity_name)
               └─ AppCore::friend(FriendCommand)
```

`liveletters-friend` сам не формирует протокольные сообщения. Он передаёт
намерение в `liveletters-app-core`, а тот решает, нужен ли обычный запрос
подписки перед добавлением в друзья.

## Состояния

### Подписка на друга уже есть

1. Сохраняется запись `friends(owner_resource_email, friend_email)`.
2. В `outbox` кладётся `friend_added`.
3. Получатель при обработке `friend_added` сохраняет у себя
   `friend_of(profile_id, resource_email)`.

### Подписки на друга ещё нет

1. Создаётся `pending_friends`.
2. Отправляется обычный `SubscriptionRequested`.
3. После входящего `SubscriptionConfirmed(accepted=true)` запись
   `pending_friends` превращается в `friends`.
4. Затем отправляется отдельное `friend_added`.

Такой порядок означает, что получатель узнаёт о дружбе только после
успешного завершения обычного цикла подписки.

## Рассылка записей

Записи с видимостью `public` отправляются подписчикам ресурса.

Записи с видимостью `friends_only` отправляются только тем подписчикам,
которые одновременно есть в таблице `friends` владельца ресурса. Поэтому
добавление в друзья само по себе не вызывает доставку записей: нужна ещё и
подписка получателя на ресурс владельца.

Комментарии наследуют фактическую видимость исходной записи. Если автор
закрытой записи комментирует её сам, комментарий рассылается тому же кругу
друзей-подписчиков, что и запись.
